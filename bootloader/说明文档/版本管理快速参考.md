# 固件版本管理 - 快速参考

## 🚀 常用命令

### 查询当前版本
```bash
python iap_upload.py -p COM3 --query-version
```

### 智能升级（推荐）
```bash
# 会自动检查版本，相同或更低版本会跳过
python iap_upload.py -p COM3 -f firmware.bin --version 1.2.3 --desc "修复bug"
```

### 强制升级
```bash
# 跳过版本检查，强制升级
python iap_upload.py -p COM3 -f firmware.bin --version 1.2.3 --force
```

### 传统升级（不带版本）
```bash
# 兼容旧方式，不使用版本管理
python iap_upload.py -p COM3 -f firmware.bin
```

## 📊 版本比较规则

版本号格式：`major.minor.patch`

比较优先级：
1. 主版本号 (major)
2. 次版本号 (minor)
3. 修订号 (patch)
4. 编译日期
5. 编译时间

示例：
- `2.0.0` > `1.9.9` ✅
- `1.3.0` > `1.2.5` ✅
- `1.2.3` > `1.2.2` ✅
- `1.2.3` = `1.2.3` (相同日期) ⚠️
- `1.2.2` < `1.2.3` ❌

## ✨ 使用场景

### 场景1: 首次烧录
```bash
# 没有版本信息，直接升级
python iap_upload.py -p COM3 -f app_v1.0.0.bin --version 1.0.0
```
结果: ✅ 升级成功并保存版本信息

### 场景2: 版本升级
```bash
# 当前: 1.0.0 → 升级到: 1.1.0
python iap_upload.py -p COM3 -f app_v1.1.0.bin --version 1.1.0
```
结果: ✅ 检测到新版本，自动升级

### 场景3: 重复烧录相同版本
```bash
# 当前: 1.1.0 → 尝试烧录: 1.1.0
python iap_upload.py -p COM3 -f app_v1.1.0.bin --version 1.1.0
```
结果: ⚠️ 版本相同，跳过升级（节省时间）

### 场景4: 版本降级
```bash
# 当前: 1.1.0 → 尝试降级到: 1.0.0
python iap_upload.py -p COM3 -f app_v1.0.0.bin --version 1.0.0
```
结果: ⚠️ 版本较低，跳过升级

### 场景5: 强制降级
```bash
# 强制降级到 1.0.0
python iap_upload.py -p COM3 -f app_v1.0.0.bin --version 1.0.0 --force
```
结果: ✅ 跳过版本检查，强制降级

## 💡 提示

### ✅ 优势
- 自动跳过相同版本，节省时间
- 防止意外烧录错误版本
- 方便版本追踪和管理
- 完全向后兼容，可选使用

### ⚠️ 注意
- 首次烧录的固件，查询版本会显示"无有效版本信息"（正常）
- 使用 `--force` 会跳过所有版本检查
- 不带 `--version` 参数时，不使用版本管理功能（兼容旧方式）
