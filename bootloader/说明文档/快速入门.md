# 快速入门指南

本指南帮助你快速上手STM32 IAP Bootloader。

## 🎯 5分钟快速开始

### 步骤1: 编译Bootloader

1. 打开Keil项目：`MDK-ARM/bootloader.uvprojx`
2. 确认链接脚本配置正确（Bootloader区域：0x08000000，大小64KB）
3. 编译项目
4. 下载到STM32板子

### 步骤2: 准备Application

1. 创建或打开你的应用程序项目
2. 修改Application的链接脚本：
   ```
   起始地址：0x08010000
   大小：448KB (0x00070000)
   ```
3. 在`main()`函数最开始添加：
   ```c
   SCB->VTOR = 0x08010000;  // 设置中断向量表偏移
   ```
4. 编译生成`.bin`文件（不是`.hex`）

### 步骤3: 配置UART（可选但推荐）

如果要使用UART协议进行固件升级：

在`main.c`的USER CODE BEGIN 2区域添加：

```c
/* USER CODE BEGIN 2 */

// 初始化UART（假设使用UART1，需要在CubeMX中配置）
MX_USART1_UART_Init();

// 初始化Bootloader UART协议
Bootloader_UART_Init(&huart1);

// ... Bootloader其他初始化代码

/* USER CODE END 2 */
```

在主循环中：

```c
/* USER CODE BEGIN WHILE */
while (1)
{
    /* USER CODE END WHILE */
    
    /* USER CODE BEGIN 3 */
    
    // 处理UART IAP命令
    Bootloader_UART_Process();
    
    HAL_Delay(10);
}
/* USER CODE END 3 */
```

### 步骤4: 上传固件

#### 方式A: 使用Python工具（推荐）

1. 安装依赖：
   ```bash
   pip install pyserial
   ```

2. 运行上传工具：
   ```bash
   python tools/iap_upload.py -p COM3 -f application.bin
   ```

#### 方式B: 手动测试

通过串口调试工具发送命令（详见《IAP_使用说明.md》）

## 🔧 最小化集成（只需跳转功能）

如果你只想要Bootloader跳转到APP的功能，最简单的实现：

### Bootloader端 (main.c)

```c
#include "bootloader.h"

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    
    // 初始化Bootloader
    Bootloader_Init();
    
    // 延迟一下，给用户按键的机会
    HAL_Delay(500);
    
    // 检查按键是否按下（需要在CubeMX中配置GPIO）
    if (HAL_GPIO_ReadPin(BOOT_KEY_GPIO_Port, BOOT_KEY_Pin) == GPIO_PIN_RESET)
    {
        // 按键按下，进入Bootloader模式
        // 在这里可以点亮LED提示
    }
    else
    {
        // 按键未按下，跳转到APP
        Bootloader_JumpToApp();
    }
    
    // 如果跳转失败或进入Bootloader模式，执行主循环
    while (1)
    {
        // LED闪烁提示Bootloader运行中
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
        HAL_Delay(500);
    }
}
```

### Application端 (main.c)

```c
int main(void)
{
    // 必须先设置中断向量表偏移！
    SCB->VTOR = 0x08010000;
    
    HAL_Init();
    SystemClock_Config();
    
    // ... 你的应用程序代码
    
    while (1)
    {
        // 你的主循环
    }
}
```

## 📋 完整的IAP升级功能

如果需要完整的固件升级功能：

### Bootloader端 (main.c)

```c
#include "bootloader.h"
#include "bootloader_uart.h"

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_USART1_UART_Init();  // 初始化UART
    
    // 初始化Bootloader
    Bootloader_Init();
    
    // 初始化UART协议
    Bootloader_UART_Init(&huart1);
    
    // 发送提示信息
    Bootloader_UART_SendString("\r\n");
    Bootloader_UART_SendString("===========================\r\n");
    Bootloader_UART_SendString("  STM32 IAP Bootloader\r\n");
    Bootloader_UART_SendString("  Version: 1.0.0\r\n");
    Bootloader_UART_SendString("===========================\r\n");
    
    // 延迟，给用户操作时间
    HAL_Delay(500);
    
    // 检查升级标志
    if (Bootloader_CheckUpdateFlag())
    {
        Bootloader_UART_SendString("Last update incomplete, entering IAP mode...\r\n");
        Bootloader_ClearUpdateFlag();
    }
    // 检查按键
    else if (HAL_GPIO_ReadPin(BOOT_KEY_GPIO_Port, BOOT_KEY_Pin) == GPIO_PIN_RESET)
    {
        Bootloader_UART_SendString("Button pressed, entering IAP mode...\r\n");
    }
    // 默认跳转到APP
    else
    {
        Bootloader_UART_SendString("Jumping to application...\r\n");
        HAL_Delay(100);
        Bootloader_JumpToApp();
        
        // 如果跳转失败
        Bootloader_UART_SendString("Application invalid, entering IAP mode...\r\n");
    }
    
    // 进入IAP模式
    Bootloader_UART_SendString("IAP mode ready, waiting for firmware...\r\n");
    
    // 主循环
    while (1)
    {
        // 处理UART IAP协议
        Bootloader_UART_Process();
        
        // LED闪烁指示
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
        HAL_Delay(100);
    }
}
```

## 🚨 常见问题快速解决

### 问题1: 编译后无法跳转到APP

**原因**: Application没有设置中断向量表偏移

**解决**: 在Application的`main()`函数最开始添加：
```c
SCB->VTOR = 0x08010000;
```

---

### 问题2: Bootloader可以运行，但下载APP后无法启动

**检查清单**:
- [ ] Application的链接脚本起始地址是`0x08010000`
- [ ] Application设置了`SCB->VTOR = 0x08010000`
- [ ] Application编译生成的是`.bin`文件
- [ ] Bootloader中`APP_START_ADDR`定义为`0x08010000`

---

### 问题3: Flash写入失败

**可能原因**:
1. Flash有写保护 → 使用STM32 ST-LINK Utility解除写保护
2. 地址不对齐 → 确保地址4字节对齐
3. 没有先擦除 → 调用`IAP_StartUpdate()`会自动擦除

---

### 问题4: Python工具连接失败

**检查**:
1. 串口号是否正确（Windows: COM3, Linux: /dev/ttyUSB0）
2. 波特率是否匹配（默认115200）
3. USB转串口驱动是否安装
4. STM32的UART是否正确初始化

**测试串口**:
```bash
# Windows
python -m serial.tools.list_ports

# 测试连接
python -c "import serial; s=serial.Serial('COM3',115200); print('OK')"
```

---

### 问题5: 升级后程序运行异常

**可能原因**:
1. 固件文件不完整 → 使用CRC校验
2. 中断向量表未设置 → 检查`SCB->VTOR`
3. 时钟配置问题 → 确保Application正确配置了时钟

---

## 📝 测试步骤

### 基本测试

1. **测试Bootloader启动**
   - 下载Bootloader
   - 观察LED闪烁或串口输出
   - ✓ Bootloader正常运行

2. **测试跳转功能**
   - 下载一个简单的Application（例如LED闪烁）
   - 复位MCU
   - ✓ Bootloader应该跳转到Application

3. **测试进入IAP模式**
   - 按住按键，复位MCU
   - ✓ Bootloader应该保持运行，不跳转

4. **测试固件升级**
   - 运行Python工具上传新固件
   - ✓ 上传成功，自动跳转到新固件

## 🎓 进阶功能

### 添加加密功能

在`bootloader.c`中实现解密函数：

```c
void DecryptFirmware(uint8_t *data, uint32_t len)
{
    // 实现你的解密算法
    for (uint32_t i = 0; i < len; i++)
    {
        data[i] ^= 0x5A;  // 简单的XOR加密示例
    }
}
```

在写入前解密：

```c
IAP_StatusTypeDef IAP_WriteData(uint32_t addr, uint8_t *data, uint32_t len)
{
    // 解密数据
    DecryptFirmware(data, len);
    
    // 写入Flash
    return Bootloader_Flash_Write(addr, data, len);
}
```

### 添加备份功能

```c
// 在升级前备份当前固件到备份区
IAP_StatusTypeDef BackupCurrentFirmware(void)
{
    uint8_t buffer[256];
    uint32_t src_addr = APP_START_ADDR;
    uint32_t dst_addr = BACKUP_START_ADDR;
    uint32_t size = APP_MAX_SIZE;
    
    // 擦除备份区
    Bootloader_Flash_Erase(dst_addr, size);
    
    // 复制固件
    for (uint32_t i = 0; i < size; i += sizeof(buffer))
    {
        Bootloader_Flash_Read(src_addr + i, buffer, sizeof(buffer));
        Bootloader_Flash_Write(dst_addr + i, buffer, sizeof(buffer));
    }
    
    return IAP_SUCCESS;
}
```
