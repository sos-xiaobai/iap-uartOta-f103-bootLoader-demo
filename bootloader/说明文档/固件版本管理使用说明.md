# 固件版本管理使用说明

## 概述

本bootloader已升级支持固件版本管理功能，可以：
- ✅ 保存和读取APP固件版本信息
- ✅ 自动比较版本号，避免重复烧录相同版本
- ✅ 支持版本回退判断
- ✅ 记录固件编译时间和描述信息

## 版本信息结构

固件版本信息包含以下内容：
- **主版本号** (major): 大版本更新
- **次版本号** (minor): 功能更新
- **修订号** (patch): bug修复
- **编译日期**: YYYYMMDD格式
- **编译时间**: HHMMSS格式
- **固件大小**: 字节数
- **固件CRC32**: 校验值
- **描述信息**: 最多32字节的描述文字

## Bootloader端功能

### 1. 版本信息存储

版本信息存储在Flash的固定位置（`0x0807F900`），使用魔术字`0x46575652`("FWVR")标识有效性。

### 2. 新增API函数

```c
/* 保存APP固件版本信息到Flash */
IAP_StatusTypeDef Bootloader_SaveAppVersion(Firmware_VersionTypeDef *version);

/* 从Flash读取APP固件版本信息 */
IAP_StatusTypeDef Bootloader_ReadAppVersion(Firmware_VersionTypeDef *version);

/* 检查APP固件版本信息是否有效 */
uint8_t Bootloader_IsAppVersionValid(void);

/* 比较两个版本号 (返回: 1:ver1>ver2, 0:相等, -1:ver1<ver2) */
int8_t Bootloader_CompareVersion(Firmware_VersionTypeDef *ver1, Firmware_VersionTypeDef *ver2);

/* 擦除APP固件版本信息 */
void Bootloader_EraseAppVersion(void);
```

### 3. 新增IAP命令

- `IAP_CMD_GET_APP_VERSION (0xA8)`: 获取当前APP版本信息
- `IAP_CMD_SET_APP_VERSION (0xA9)`: 设置APP版本信息
- `IAP_CMD_COMPARE_VERSION (0xAA)`: 比较版本（判断是否需要升级）

## Python工具使用

### 1. 查询当前APP版本

```bash
python iap_upload.py -p COM3 --query-version
```

输出示例：
```
当前APP版本信息:
版本: 1.2.3
  描述: 修复蓝牙连接bug
  编译日期: 20241106
  编译时间: 153045
  固件大小: 45678 字节
  固件CRC32: 0x12345678
```

### 2. 带版本信息升级（自动检查版本）

```bash
python iap_upload.py -p COM3 -f firmware.bin --version 1.2.3 --desc "修复bug"
```

升级流程：
1. 读取固件文件并计算CRC32
2. 连接设备并获取Bootloader信息
3. **比较版本号**
   - 如果新版本 > 当前版本：继续升级
   - 如果新版本 <= 当前版本：跳过升级
4. 擦除APP区域并写入固件
5. **保存版本信息**
6. 结束升级，设备重启

### 3. 强制升级（跳过版本检查）

```bash
python iap_upload.py -p COM3 -f firmware.bin --version 1.2.3 --force
```

即使版本相同或更低，也会强制升级。

### 4. 不带版本信息升级（兼容旧版本）

```bash
python iap_upload.py -p COM3 -f firmware.bin
```

保持兼容性，不使用版本管理功能。

### 5. 指定编译时间

```bash
python iap_upload.py -p COM3 -f firmware.bin --version 1.2.3 \
  --build-date 20241106 --build-time 153045 --desc "新功能"
```

如果不指定，会自动使用当前系统时间。

## 版本比较规则

版本比较按以下优先级进行：
1. **主版本号** (major)
2. **次版本号** (minor)
3. **修订号** (patch)
4. **编译日期** (build_date)
5. **编译时间** (build_time)

例如：
- `2.0.0` > `1.9.9`
- `1.2.3` > `1.2.2`
- `1.2.3 (20241106)` > `1.2.3 (20241105)`

## 升级场景

### 场景1: 首次烧录固件

```bash
# 没有版本信息，直接升级
python iap_upload.py -p COM3 -f app_v1.0.0.bin --version 1.0.0
```

结果：
- ✓ 检测到当前无版本信息
- ✓ 建议升级
- ✓ 写入固件并保存版本信息

### 场景2: 升级到更高版本

```bash
# 当前版本：1.0.0，升级到 1.1.0
python iap_upload.py -p COM3 -f app_v1.1.0.bin --version 1.1.0
```

结果：
- ✓ 当前版本: 1.0.0
- ✓ 新版本: 1.1.0
- ✓ 新版本较高，需要升级
- ✓ 写入固件并更新版本信息

### 场景3: 尝试烧录相同或更低版本

```bash
# 当前版本：1.1.0，尝试烧录 1.0.0
python iap_upload.py -p COM3 -f app_v1.0.0.bin --version 1.0.0
```

结果：
- ℹ 当前版本: 1.1.0
- ℹ 新版本: 1.0.0
- ℹ 版本相同或新版本较低，无需升级
- ℹ 跳过升级（节省时间，避免不必要的Flash擦写）

### 场景4: 强制降级

```bash
# 强制降级到 1.0.0
python iap_upload.py -p COM3 -f app_v1.0.0.bin --version 1.0.0 --force
```

结果：
- ⚠ 跳过版本检查
- ✓ 写入固件并更新版本信息

## 与旧版本兼容性

- ✅ 完全向后兼容：不带`--version`参数时，工作方式与旧版本完全相同
- ✅ 旧的APP可以通过带版本信息的方式升级
- ✅ 新的APP可以不带版本信息升级（但不推荐）

## 最佳实践

### 1. 版本号管理

建议使用语义化版本号：
- **主版本号**: 重大架构变更或不兼容的API修改
- **次版本号**: 新功能添加，保持向后兼容
- **修订号**: bug修复和小改进

### 2. 升级工作流

```bash
# 开发阶段：使用 --force 快速迭代
python iap_upload.py -p COM3 -f debug.bin --version 0.1.0 --force

# 测试阶段：正常版本检查
python iap_upload.py -p COM3 -f test_v1.0.0.bin --version 1.0.0

# 生产发布：严格版本管理
python iap_upload.py -p COM3 -f release_v1.0.0.bin \
  --version 1.0.0 --desc "正式发布版本"
```

### 3. 批量升级脚本

可以创建批量升级脚本，自动跳过已是最新版本的设备：

```bash
#!/bin/bash
# batch_upgrade.sh

for port in COM3 COM4 COM5 COM6; do
    echo "升级设备: $port"
    python iap_upload.py -p $port -f firmware.bin \
      --version 1.2.3 --desc "批量升级"
    echo "---"
done
```

## 故障排查

### 问题1: 版本信息保存失败

```
⚠ 版本信息保存失败，但固件已写入
```

**原因**: Flash写入版本信息时出错
**解决**: 
- 固件已成功写入，可以正常运行
- 下次升级时会提示无版本信息
- 可以手动再次升级并保存版本信息

### 问题2: 版本比较失败

```
✗ 版本比较失败: STATUS=0x01
```

**原因**: 通信错误或Bootloader未响应
**解决**:
- 检查串口连接
- 重启设备后重试
- 使用 `--force` 跳过版本检查

### 问题3: 查询版本时显示无效

```
当前无有效的APP版本信息
```

**原因**: 
- 首次烧录，还没有版本信息
- 使用旧版本工具烧录的固件
- 版本信息区域被擦除

**解决**: 
- 正常现象，使用 `--version` 参数升级即可保存版本信息

## 技术细节

### Flash布局

```
0x08000000 ┌─────────────────┐
           │   Bootloader    │
           │     (64KB)      │
0x08010000 ├─────────────────┤
           │                 │
           │   APP区域       │
           │   (448KB)       │
           │                 │
0x0807F800 ├─────────────────┤
           │  升级标志       │
0x0807F900 ├─────────────────┤
           │  版本信息(80B)  │ ← 新增
0x08080000 └─────────────────┘
```

### 版本信息数据结构 (80字节)

```c
typedef struct {
    uint32_t magic;        // 魔术字: 0x46575652
    uint8_t  major;        // 主版本号
    uint8_t  minor;        // 次版本号
    uint16_t patch;        // 修订号
    uint32_t build_date;   // 编译日期
    uint32_t build_time;   // 编译时间
    uint32_t app_size;     // 固件大小
    uint32_t app_crc32;    // CRC32校验
    char     description[32]; // 描述信息
    uint32_t reserved[4];  // 保留字段
} Firmware_VersionTypeDef;
```
